BOM 选型台

上传 BOM → 锁定规格 → 本地会话执行到购物车

规则决策 + 本地执行 只到购物车 付款人工

1上传 BOM

CSV / XLSX，至少要有「型号」或「名称」，建议带「封装 / 参数 / 数量」

2选型答案

选择左侧任意一行，查看采购口径、搜索词与风险。

3候选评分可选

把你看到的候选粘进来，按 SKILL 权重打分；本页不抓取、不访问任何平台

示例候选是合成数据，仅用于演示评分逻辑；评分只使用你粘贴的字段，不抓取。真正访问淘宝只在下方「淘宝执行」区。

4淘宝执行只到购物车

未启动
逐行搜索 → 取通过硬门槛的候选里最便宜的一个 → 匹配 SKU → 加购；某一行失败会自动换下一个候选。
会话就绪后选一行搜索；候选按规则打分，再由你确认打开和加购。
购物车维护（删除 / 测试用）
删除只影响淘宝购物车，不可撤销；清空会连同你自己加的商品一起删掉。
会话日志（排查用） 

    

    
执行层只调用 search / open / select-sku / cart-add；付款、地址、发票必须你本人在淘宝完成。遇到验证码请手动完成，站点不会绕过。
